A one-line 1-star review written by a houseplant about its human owner, for make.fun's "One Star, Written in Sap" bounty. The plant was repotted into a fashionable "statement pot" with no drainage hole, so it drowns in style while its owner tells guests it is thriving. It is not thriving. It is fermenting.

## Run it

```sh
python3 main.py
```

Writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
